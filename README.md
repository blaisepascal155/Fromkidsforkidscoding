# 🚀 From Kids For Kids Coding

A fun, interactive coding website designed to teach kids how to code in an engaging and accessible way!

## Features

✨ **Interactive Learning Paths**
- Web Design (HTML, CSS, JavaScript)
- Game Development
- Python Basics

🎮 **Fun Challenges**
- Number guessing game
- Color identification game
- Interactive coding tutorials

🎨 **Kid-Friendly Design**
- Colorful, engaging interface
- Smooth animations
- Mobile-responsive
- Easy navigation

## What's Included

- `index.html` - Main website structure
- `styles.css` - Beautiful styling and animations
- `script.js` - Interactive features and games

## Getting Started

1. Open `index.html` in your web browser
2. Explore the different learning paths
3. Try the challenges and test your coding knowledge!
4. Learn at your own pace

## Learning Sections

### 🎨 Web Design
Learn the basics of HTML, CSS, and JavaScript to build your own websites.

### 🎮 Game Development
Create interactive games using JavaScript and game development concepts.

### 🤖 Python Basics
Start your coding journey with Python - one of the easiest languages to learn!

## Interactive Challenges

- **Guess the Number** - Practice logical thinking
- **Color Name Game** - Test your knowledge while having fun

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript
- Responsive Design

## Tips for Learning

1. Start with the Web Design section
2. Try each challenge multiple times
3. Experiment with the code - change values and see what happens!
4. Don't be afraid to make mistakes - that's how you learn!
