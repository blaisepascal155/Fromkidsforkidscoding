🎨 Web Design

Learn to build beautiful websites with HTML, CSS & JavaScript!

Lesson 1: HTML Basics

What is HTML?

HTML stands for HyperText Markup Language. It's like the skeleton of a website - it creates the structure and content!

Your First HTML Tag:

<h1>Hello World!</h1>

This creates a big heading that says "Hello World!"

Common HTML Tags:

  • <h1>...</h1> - Main heading (biggest)
  • <h2>...</h2> - Subheading
  • <p>...</p> - Paragraph of text
  • <img src="..."> - Display an image
  • <a href="...">Link</a> - Create a link
  • <button>Click Me</button> - Create a button

Lesson 2: CSS Styling

What is CSS?

CSS stands for Cascading Style Sheets. It makes websites look beautiful by adding colors, fonts, and layouts!

Basic CSS Properties:

  • color: red; - Change text color
  • background-color: blue; - Change background color
  • font-size: 20px; - Make text bigger or smaller
  • border: 2px solid black; - Add a border
  • padding: 10px; - Add space inside an element
  • margin: 10px; - Add space outside an element

Example CSS:

h1 { color: purple; font-size: 48px; text-align: center; }

Lesson 3: JavaScript Interactivity

What is JavaScript?

JavaScript is what makes websites interactive! It allows you to respond to user clicks, create animations, and more!

Basic JavaScript:

function sayHello() { alert("Hello, World!"); }

Try It Out:

What Makes JavaScript Awesome:

  • ✅ Respond to clicks and typing
  • ✅ Create smooth animations
  • ✅ Store information (variables)
  • ✅ Make games and interactive apps
  • ✅ Validate forms before sending data
