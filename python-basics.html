🤖 Python Basics

Start your coding journey with one of the easiest programming languages!

Lesson 1: Your First Program

Hello, Python! 👋

Let's start with the most basic Python program - printing text!

Your First Line of Code:

print("Hello, World!")

When you run this, Python displays: Hello, World!

What is print()?

print() is a function that displays text on the screen. Think of it like Python saying something out loud!

Lesson 2: Variables & Data Types

Storing Information

Variables are like containers that hold information. You can store numbers, text, and more!

Creating Variables:

name = "Alex" age = 12 height = 5.5 print(name) # Prints: Alex print(age) # Prints: 12

Data Types:

  • String (text): "Hello" or 'Python'
  • Integer (whole number): 5, 100, -10
  • Float (decimal): 3.14, 2.5, -7.2
  • Boolean (true/false): True or False

Lesson 3: Math & Operations

Python Can Do Math!

Use Python to perform calculations. It's like having a super-smart calculator!

Basic Math Operations:

  • 5 + 3 → 8 (Addition)
  • 10 - 4 → 6 (Subtraction)
  • 6 * 7 → 42 (Multiplication)
  • 20 / 4 → 5 (Division)
  • 2 ** 3 → 8 (Power/Exponent)
  • 17 % 5 → 2 (Remainder)

Math Example:

price = 25 quantity = 3 total = price * quantity print(total) # Prints: 75

Lesson 4: If Statements (Decisions)

Making Decisions in Your Code

If statements let your program make decisions based on conditions!

Basic If Statement:

age = 13 if age >= 13: print("You're a teenager!") else: print("You're not a teenager yet.")

Comparison Operators:

  • == equals
  • != not equals
  • > greater than
  • < less than
  • >= greater than or equal
  • <= less than or equal

Lesson 5: Loops (Repetition)

Doing Things Over and Over

Loops let you repeat code without writing it many times!

For Loop Example:

for i in range(5): print(i) # Prints: 0, 1, 2, 3, 4

While Loop Example:

count = 0 while count < 3: print("Count:", count) count = count + 1
