Lesson 1: Game Loop Basics

What is a Game Loop?

Every game has a loop that keeps running! It updates the game and draws everything on screen, over and over, very fast!

The Basic Game Loop:

function gameLoop() { updateGame(); // Update positions, check collisions drawGame(); // Draw everything on screen requestAnimationFrame(gameLoop); }

Why It Matters:

  • 🔄 Runs ~60 times per second
  • 🎯 Creates the illusion of movement
  • 🕹️ Checks for player input (keyboard, mouse)
  • 💥 Handles collisions and game events

Lesson 2: Player Movement

Making Things Move!

To move objects, we change their position a little bit each frame. This creates smooth movement!

Movement Code:

let playerX = 50; function update() { if (keys.ArrowRight) playerX += 5; if (keys.ArrowLeft) playerX -= 5; }

Lesson 3: Collision Detection

Detecting When Objects Touch

In games, we need to know when objects collide! This is used for collecting items, taking damage, and more!

Simple Collision Check:

function checkCollision(obj1, obj2) { return obj1.x < obj2.x + obj2.width && obj1.x + obj1.width > obj2.x && obj1.y < obj2.y + obj2.height && obj1.y + obj1.height > obj2.y; }

Lesson 4: Game States

Menu, Playing, Game Over!

Games have different states: Start Menu, Playing, Paused, and Game Over. We control what happens in each state!

Game States Example:

let gameState = "menu"; // Can be "menu", "playing", "gameOver" if (gameState === "menu") { drawMenu(); } else if (gameState === "playing") { updateGame(); drawGame(); } else if (gameState === "gameOver") { drawGameOver(); }
